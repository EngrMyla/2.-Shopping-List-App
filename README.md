# Shopping List App

A simple Python-based shopping list application that let users add, view, sort, update, and remove items from their shopping list.

### Features
- Add shopping item and respective quantity
- View shopping list
- Sort items by quantity
- Update quantity per item
- Remove item from the shopping list

### How to Run
1. Open the project folder.
2. Make sure that Python is installed on your device.
3. Run the following command in PowerShell:
```bash
py shopping_list.py
```
4. Navigate and interact with the app.

### Requirements
- Python 3.x
